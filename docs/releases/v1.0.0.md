# 《我的相亲对象们有点怪》· 雨夜试约 v1.0.0

一个使用 Ren'Py 开发的现代都市、克系恋爱视觉小说 Demo，单周目约 5–8 分钟。

## 下载与运行

1. 在本页 **Assets** 下载 **StrangeDates-1.0-win.zip**。
2. 解压整个压缩包，进入 `StrangeDates-1.0-win` 文件夹。
3. 双击 **StrangeDates.exe** 开始体验。

Windows 版自带运行时，无需安装 Ren'Py 或 Python。包内的 **README-HR.html** 可离线阅读，介绍作品概念、亮点、人物与操作。

GitHub 自动生成的 **Source code (zip)** / **Source code (tar.gz)** 为源码，试玩请选择上方的 Windows 压缩包。

## 体验内容

- 三位现代都市少女，分别改写克苏鲁、犹格·索托斯与奈亚拉托提普的意象。
- 三段约会、两次前置选择、三种恋爱结局与一条离席结局。
- 用雨声、空镜与时间错位表现主角视线之外的异常，无具象恐怖画面。
- 定制界面、存读档、对话回看、自动播放、人物档案与跨周目结局回收。
- 结局页可直接重选，方便短时间内查看其他路线。

## 操作与验证

左键 / 空格推进；Esc / 右键打开设置；滚轮向上回看；H 隐藏界面。建议以舒适音量开启环境声。
