01 / Concept

一张桌子，三封邀请。

二十七岁的编辑林予，在雨夜收到三份同一时间的相亲邀请。三位姑娘看起来都很正常，聊工作、早餐和喜欢的火锅。但当他低头捡起餐巾、转身向店员道谢时，世界会悄悄偏离一点。

这是一段带着温度的克系恋爱故事：把不可知的力量藏进约会里的小细节，用空镜、停顿与声音让读者意识到，自己比主角多看见了一点。

01

人物关系先于谜底

三次短约会围绕耐心、未知与真实展开。两次对话选择改变回应，最后的同行选择完成情绪收束。

02

恐怖发生在视线之外

角色保持正常的人类形象。异常通过撤去立绘、环境色调、空镜文字与声音呈现，没有实体怪物、血腥或突发惊吓。

03

一段完整的可玩体验

定制标题页、人物档案、存读档、历史回看与结局回收册。支持自动阅读、声音调节及减少动态雨丝。

Production Notes

关于制作方式

本项目根据用户提出的主题、现代服装要求及提供的风格参考，使用 Codex 协作完成剧本、界面、程序与整合。人物和背景使用 OpenAI 图像生成工具制作；声音由程序合成；中文字体为 Source Han Sans Lite，许可证随发行包保留。

制作重点是将角色设定、分支叙事、界面与音画演出整合为完整的短篇体验。源码附有中文注释，保留美术提示和音效生成程序，便于继续开发与复盘。

Scope & Verification

关于这份 Demo

目标是展示一个可运行的短篇叙事切片：三段约会、轻量分支和四种收束。三位角色统称“克系原型改写”；人类身份与恋爱性格属于本作创作，不作神话分类考据。

完成验证 · 2026.10.10

Ren'Py Lint、界面操作、真实存读档恢复、共通剧情与四结局测试均已通过。解压 Windows 发行包后，使用其自带运行时再次通过两组测试；已复核 17 张实际引擎截图。源码、字体许可与本说明随包提供。
